<h2>Lyric Forge</h2>

Lyric forge is a basic Lyric-Video generator for social content.

<h4>How it works:</h4>
1. Upload your audio. This can be in the form of MP3, WAV, M4A, AAC, OGG, or flac FLAC.

2. Paste in and time sync your lyrics

3. Upload your own videos, or enter your Pexels API key, which can be found for free at <a href=https:www.pexels.com/api> pexels.com/api </a> and choose videos from in the application.
  
4. Customize text details, fonts, positions, credits, and more!
5. Save and load projects for future use

<h4>Installation</h4>
Installation is very easy, just download the .exe file and run in on your computer.
